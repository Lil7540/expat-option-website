# EXPAT OPTION WEBSITE

This repository contains a starter website for EXPAT OPTION with:

- Landing page for the brand
- Investment plan section
- Payment details for deposits and withdrawals
- Dashboard view for balance and transactions
- Deposit and withdrawal forms for demo use
- Simple client-side state management in JavaScript

## Run locally

Open `index.html` directly in a browser, or run a simple local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Notes

This is a front-end prototype for demonstration purposes. It does not connect to a real payment processor or live backend yet.
